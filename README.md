# Cox-Ingersoll-Ross (CIR) Process Age Inference Algorithm for Age Estimation (v.1.0)

This software is for aligning sediment cores containing benthic δ18O and/or 14C records, by following the algorithms in the paper [Lee et al. (2026), "CIR Process Age Inference Algorithm v1.0: scalable and consistent sedimentation rate modeling for ocean sediment cores via the Cox-Ingersoll-Ross process", GMD] which is now available at https://egusphere.copernicus.org/preprints/2026/egusphere-2026-2299/, running on Python.
