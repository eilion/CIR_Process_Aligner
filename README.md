# Cox-Ingersoll-Ross (CIR) Process Age Inference Algorithm for Age Estimation

This software is for aligning sediment cores containing benthic δ18O and/or 14C records, by following the algorithms in the paper [Lee et al. (2026), "Scalable and consistent sedimentation rate modeling via the Cox-Ingersoll-Ross (CIR) process for ocean sediment core age model development", GMD] which is now available at xxxx, running on Python.
